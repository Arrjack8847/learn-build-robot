# J1234 Phase 06 — integrated dashboard statistics
All statistics derive from the complete approved J1234 student directory before filtering/pagination (maximum five approved test inboxes, 50 children each). The same response contains page rows and server-derived overview. Unique canonical student IDs and charge IDs, MYR36000 minor units and HitPay sandbox evidence required. Counts cover registration/PIN readiness, membership statuses, payment status by student, today's MYT booking/check-in/check-out/no-show/excused states, check-in share (attended including checked-out / all daily bookings), current-day open attendance markers, all-time and current MYT month verified gross sandbox charges. Charges under policy review excluded from verified totals, separately display historical gross held amounts, not actual refunds or net collections. Incomplete reads/holds produce partial coverage and null full totals with labeled known subtotals; disabled gates produce unavailable/null even with no students. Missing/invalid/duplicate records never silently contribute. No simulated SGD, fixture deposits or inferred J5 progress. No deposits, net revenue or currently learning values. Directory snapshots use one evaluation instant, reject crossing MYT midnight; reads across collections are not a transaction and displayed values are committed-ledger snapshots, not provider live status. Same-day attendance only; cannot count overnight presence or live learning entitlement. Overview refreshed on attendance actions and manual refresh, search/pagination don't change scope. Single responsive student card avoids duplicate mounted controls; server confirmation refresh preserves current issued code only when status and expiry still match. No automatic polling, actual production staff authorization still release gate. Existing protected preview flags stay unset; no live payment, email, actual database write, deployment, main/J4/J5 changes. Native fixture checks cover full dataset, filtered pages, payment review, check-in/check-out/no-show, disabled/partial data, MYT month boundary and duplicates. Full build/browser acceptance deferred to later phases.
