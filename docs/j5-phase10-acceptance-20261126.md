Source requirements: J5.12–J5.30 and mandatory independent completion gate in the supplied J5 brief. Latest Codespaces evidence: private build and Chromium fixture smoke passed, 226 native tests previously confirmed, full typecheck exit 2. This phase does not merge or deploy.

## Changes
- Routine course authorization polling no longer invalidates the shared session or unmounts a currently valid lesson. Session invalidation still clears it; 5-second timeout fails closed. Overview polling no longer aborts check-in requests or resets forms via global invalidation; global logout/expiry/visibility invalidation remains. Browser rerun required.
- Private UI does not load or save shared legacy progress storage. Legacy activity completion returns false with an explicit unavailable message while verified student progress storage is not connected. This is a fail-closed interim state, not completed activity persistence.
- New server-only committed-progress projection: accepts only student-bound committed records, explicit approved versioned requirements, valid committed level states, and unique attempt snapshots. Opening a document or reference review alone never counts as educational completion. Repeated successful attempts fulfill one requirement only. Failed retries do not erase completion. Does not unlock levels. Resume candidate requires a server catalog match and fresh course authorization; no arbitrary destination. New tests include SQLite fixture isolation; not a Wix database adapter, not mounted or connected yet. No change to legacy quiz, challenge, learning art, or source PDFs.

## Integration contract
The J1-authorized Wix provider must supply coherent student-owned snapshots, explicit approved policy (version and mandatory requirements per level), committed attempt records (one row per attempt, keyed by student and attempt), and committed level states. Database transactions, uniqueness and authorization must be enforced at the write boundary; a client cannot supply approval, pass/fail, level unlock or student ID. Level 1 approved 3/4 and overtime allowed, 15 minutes; existing backend challenge-rules.js still 4/5 and no overtime pass. Other levels' progression/assessment policies must be verified rather than inferred. No approval of new weighting or threshold is assumed. Staff consume the same projection; no independent calculation or undocumented write. Actual Wix permissions, write transactions, persistent attempts, server quiz bank/grade, challenge selection/assessment, exact resume route integration and private storage remain open.
