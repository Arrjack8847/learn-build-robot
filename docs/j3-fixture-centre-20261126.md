# Standalone J3 fictional testing foundation
Owner scope: five fictional payers, two students each, payer only handles payment; each student has individual status. MYR360 membership, MYR50 deposit, Touch n Go only. No real accounts, payment calls, credentials, email delivery or J2/J4/J5 integration. Process-local isolated fixture centre with session handles, fixed prices, duplicate prevention, payment and event conflict checks, simulated two-cycle renewal, deposit separation, student projection and simulated notification outbox. Fixtures are deliberately not provider evidence; all student projections deny verifiedLearningEligibility. No HTTP mounting or persistence. UI and durable private test session adapter pending. No live payment operations until existing credential and webhook checks are resolved. Run node --test tests/hitpay-j3-fixture-centre.test.mjs. 

Standalone interface mounted at /dev/j3-testing-centre only when VERCEL_ENV=preview and exact J3 branch, never production. Fictional data is tab-local in memory; no real session or network. CSP blocks network connections, external scripts and framing. Test payer selector, student profile, checkout, paid/failed/replay/renewal, clock advance, history and unsent confirmation previews. Test access is additionally subject to existing Vercel deployment protection. Browser visual and interaction QA pending.
