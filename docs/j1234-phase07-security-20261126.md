# J1234 Phase 07 — security and consistency hardening
Private fictional preview only. No production staff accounts, extra staff login flow, real payment or actual email. Phase 07 adds an independent test operator capability to directory/overview and attendance mutations, on top of deployment protection, exact branch/site/origin, same-origin and explicit gates. Requires J1234_TEST_OPERATOR_ENABLED=1 and separately generated J1234_TEST_OPERATOR_SECRET (256-bit hex), not shared with auth root, payer/student keys or membership worker. The dashboard accepts the key in page memory; no persistence, URL, client build-time secret or staff account. This is an additional test-only access check, not actual production staff authorization. No secret has been provisioned, all flags stay unset. Browser actor cookies alone do not grant authority. Worker rejects operator-secret reuse. Production and legacy endpoints remain denied; student code redemption still uses the individual server-resolved session without the operator key.
Attendance audit state is replayed and validated against durable aggregate, including timestamps, actor, unique request IDs, transition/result, code attempt counts, issue limits, fingerprint uniqueness and check-in/check-out markers. Corrupt or future attendance returns verification_required, not a valid visit. Recheck credential version and membership before CAS, exact code type; cross-collection race remains possible and future learning access must independently recheck both. Directory checks full family/consent snapshot and PIN versions again before returning; profile/list/consent changes fail closed instead of leaking stale rows. Billing projection requires durable dispatched bound reservation; malformed reserved payments fail closed. Still not a cross-collection database transaction; later live verification and genuine provider worker delivery are mandatory. No real staff identity, no J5 integration or production modifications. Regression uses mocked transport/database only. Full build and browser acceptance deferred.
