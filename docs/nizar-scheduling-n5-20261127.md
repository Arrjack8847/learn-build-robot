All ten operating hours, two independent capacity pools, offered places and queued places, cancellations, attended/check-out, no-shows, excuses and held-unpaid rows. No new code generation or pass issuance implemented. N4 excuse action checks revision where supplied. No-show classifier must only use canonical negative observation when real J5 is integrated; the separate fixture cannot supply it.

Private route /dev/nizar-staff and POST /api/dev/nizar/staff, exact Nizar branch and HTTPS host, scheduling/parent fixture flags plus NIZAR_STAFF_FIXTURE_ENABLED=1 and separate 64-hex NIZAR_STAFF_FIXTURE_KEY. Fictional families only. Staff key never accepted by parent endpoint or vice versa. UI day selection, status filters, totals, slot list, current-hour walk-in, manual mark present/check out and excuse. No real staff authentication connected. No actual records created or changed by this implementation turn.

Verified redemption commits attendance to the same aggregate before granting a pass; actual code-consumption/pass issuance atomicity and checkout revocation must be reviewed in integration. Existing integration branch untouched.
